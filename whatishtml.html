Introduction

What is Programming/Coding?

The terms programming and coding are interchangable. But sometimes, "programming" is less specific than "coding".

Programming refers to the action of making things using the language of computers. When you program, you are building.

Coding refers to writing the commands. Coding is the actual action of talking to the computer.

To put it simply, programming is building the project, coding is writing in the language of the computer in order to build your project.
