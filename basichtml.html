Basic HTML Tags

What is an HTML Teg?

A tag is a piece of a command that you usually see within a greater than and less than symbol.

<p>

<p> is a basic HTML tag. The "p" stands for "paragraph" and when you use the command, you'll be making a paragraph. Although, in order to complete your command, you will need to convert it into an element by adding a closing element (as <p> is an opening tag) and the content.

Here is what a full element would look like.

<p>This is my paragraph.<p>

NOTE: Not every tag needs content or a closing tag.

HTML Tags

Heading Tags

For headers, you have 6 different sizes. h1 is the largest. h2 is second to largest. And h6 is the smallest heading.

<h1>This is my heading<h1>

Ex:

This is my heading

This is h2

This is h6

Break and Divider

These tags do not need content or closing tags.

<br> < (br is the break) <hr> (hr is the divider)

Ex:

There's a break under this. Right below the break, there is a divider.



Bold and Italic Text

<b>You can also use "strong".</b> <i>You can also use "em" to "emphasize" the text</i>

Ex:

Hello this is my text. I want to emphasize that this is my text.

The Ordered and Unordered List Tags

These tags only tell the computer what kind of list you want. To add the list content, you must add the list (<li>) tag between the opening and closing ordered or unordered list tags.

<ol> (this is an ordered list. unordered is "ul") <li>The list content </li> </ol>

Ex:

This is an ordered list

  1. Eggs
  2. Milk
  3. Coffee

Below is my unordered list

  • Button number one
  • You can change the bullet using CSS
  • Otherwise, it will pop out as a normal bullet point

The Image Tag

Like the break and divider tags, the image tag is a self-closing tag.

<img src="add the source of your image">

"src" (source) is where you would put the link to your image, or (if you uploaded your image onto your code editor) the inside source link.

You will learn about how to use "src" as well as other attributes in the next lesson!
